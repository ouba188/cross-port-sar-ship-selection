# SREE v5（正确版：联合相对不确定性 + Fusion 默认门控）· 结论

日期 2026-10-07。23 港 × 5 seed，query\ann。Monte Carlo 50 样本采样 f_T 后验。

## 修正点（对 v1–v4 的 bug 修复，用户/外部评审逐条核实）
1. **v4 没实现"共同误差抵消"**：旧版 `sigma = sqrt(Mahal_b/(τ+n_b) + Mahal_e/(τ+n_e))` 直接相加两方差、无协方差项，且根本没接 v3 的共享因子（用的 shared_cov 独立适配）。⇒ 正确版：Monte Carlo 采样同一 f_T 后验 → d=ℓ(e)-ℓ(b) 的样本方差**自动含协方差**。
2. **v4 默认收缩向更弱的 VV**：`switch=D&(z>c); pred=where(switch,eq,bq)`，c 增大回到 VV。⇒ 正确版：**默认 Fusion，z<−c 才切 VV**。
3. **v3 只补未观察类**：`if c not in obs_cls`，且 f_T 无 n_c 加权、不确定性不进预测分布。⇒ 正确版：共享因子覆盖**所有类**，f_T 按 n_c 加权 LS，观察类向共享预测收缩（κ=8）。
4. **校准置信度实验混杂**：`zscore(s2)+zscore(conf)>0` 减均值移了原阈值。
5. **结论过度**：把"若干简化实现无优势"扩成"信息论不可估"。

## 结果
| 方法 | BA |
|---|---|
| Fusion（默认专家） | 0.4709 |
| 独立似然门控（双向 sign） | 0.4759 |
| s2（当前方法） | 0.4791 |
| 联合门控 jnt0.0 | 0.4787 |
| 联合门控 jnt1.0 | 0.4786 |

- jnt vs s2：Δ≈−0.0005，正港 13/23，**p=0.87（打平）**。
- jnt vs Fusion：**+0.008**（显著更好）。
- 挽回/错误切换（相对 Fusion，eval 分歧样本）：
  - jnt0.0：挽回率 0.502，错误切换率 0.205，净 +1526 样本。
  - jnt1.0：挽回率 0.451，错误切换率 0.178，净 +1470。

## 诚实裁决（取代旧"45% 墙"）
1. **正确机制真实成立**：Fusion 默认 + 协方差感知联合不确定性，抓到 ~50% 的 VV 挽回信号、错误切换仅 18–20%，净正、显著超 Fusion。**旧结论"信息论不可估"作废**。
2. **但它是 s2 的等价替代，不是升级**：jnt≈s2（p=0.87）。共享均值 + 联合不确定性带来的信息，与 s2 的 min-over-supports 类证据基本重合。
3. 方向 B 的诚实状态：**"联合估计机制已验证（成立、等价 s2）"**，而非"已关闭"。能否超越 s2（如与 s2 组合、源港留出定 κ、或改用似然比而非马氏距离）尚未试。
