# SREE 第一个实验（最简共享模型）· 结论 v1（负结果）

日期 2026-10-07。判据见 SREE_PREREG_v1.md。23 港 × 5 seed，统一口径 query\ann。

## 结果
| | 独立适配（当前 shared_cov） | 共享适配（借用观察类平均漂移） |
|---|---|---|
| 总体 BA | 0.4759 | 0.4755 |
| 总体 ACC | 0.4962 | 0.4954 |
| 未观察类 acc（13 港有未观察类） | 0.3659 | 0.3660（Δ +0.0001） |

- 未观察类 paired：正港 1/13，Wilcoxon p=1.0000。

## 裁决
- **主判据 FAIL**：最简共享模型（把观察类平均漂移 δ̂_T 借给未观察类）对未观察类门控**零改善**。
- **次判据 FAIL**：总体 BA/ACC 也不升（0.4759→0.4755）。

## 诚实解读
1. 最简"共享"（单一全局漂移）不成立：未观察类的真实漂移**不是**观察类平均漂移能预测的——共享信号在此数据上弱。
2. **测量口径隐患**：门控只依赖 ℓ(b)、ℓ(e)（预测类）。借用只改未观察类的均值，仅当**预测类 b/e 本身未观察**时才影响门控；"真实类未观察"与"预测类未观察"不等价。当前指标可能没干净捕捉借用效果。
3. 因子模型（W_c f_T，源侧学类专属载荷）比"平均漂移"更精细，是真正的"跨港共享结构"测试——但最简版失败是警告信号。

## 决策点（待用户定）
- **A1（再试一次）**：实现因子模型 W_c f_T（r=1 或 2，源侧 SVD 学类专属载荷，目标 64 标签估 f_T），并修正测量口径（按"预测类是否未观察"拆分）。这是"共享相对证据"的实质测试。
- **A2（收手）**：承认共享结构在冻结 PCA 特征上弱，SREE 方向证伪，回退选项 A（诚实重构投 TGRS/JSTARS）。

## 背景账（累积的墙）
- 因果因子挖掘（不变性排序）→ 失败（inv≈spu）。
- SREE 最简共享 → 失败（Δ+0.0001）。
- 两者同向：**"跨港共享结构/不变结构"在冻结 PCA 特征上不可挖**。这是方向 B 的核心风险，已两次预警。
