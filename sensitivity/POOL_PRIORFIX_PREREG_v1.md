# 键的标签漂移校正 · 预注册 v1（第二篇入口测试）

日期：2026-10-05。前置：`POOL_FAILURE_ATTRIBUTION_v1.md` —— 5% 预算内可拣头部 +2.18pp，源侧只带过 5.0%。

## 假设
键跨域失效的**一部分**来自目标域类别先验漂移（源港与目标港类别构成不同）；用**无标签**的目标先验估计
（BBSE/EM 标签漂移校正）重加权源侧键表，应把 rank5 从 +1.00pp 拉向 truegain5 的 +3.07pp。

## 方法（无标签，仅用目标未标注行的 base 预测 + 源侧混淆矩阵）
1. 源侧混淆 `C[i, c] = P(base_pred=i | y=c)`（港×类均衡权）；
2. 目标边际 `q[i] = P(base_pred=i)`（目标未标注行）；
3. EM 估 `π̂_tgt`：`π ← π ⊙ Cᵀ(q / (Cπ))`，归一，20 次迭代，初值 = 源先验；
4. 重加权键表：`p'_m(c | base=i) ∝ p_m(c | base=i) · (π̂_tgt[c]/π_src[c])`，再归一；
5. 期望增益与排序同原臂，5% 绑定预算。

## 判据（8 港诊断集）
- **主**：`rank5_priorfix − rand5 ≥ 0.5pp`（即比随机多带过 0.5pp 以上信息）；
- **次**：`rank5_priorfix − rank5 ≥ 0.5pp`；
- **上界参照**：`truegain5 − rand5 = 2.18pp`（非部署），报捕获率 = 增量/2.18pp。
全不过 ⇒ 先验漂移不是主因，键失效属更深的**条件关系**错位（留第二篇换机制）。

## 边界
- 只用目标未标注行，**不用目标标签**；π̂ 估不准会伤及排序，如实报告（含负值）；
- 不替换冻结主线，本实验只针对池/键路径。
