# 因果因子挖掘（跨港不变性）· 预注册 v1

日期 2026-10-06。目标：检验"跨港不变特征维（因果因子）"能否从现有多港结构里挖出，并提升迁移。

## 定义（因果因子的可操作判据）
- 环境 = 源港（LOPO 下其余 22 港）；结局 Y = 船类；候选因子 = 192 维 [VV-128|VH-64]。
- 因子 j 的**不变性分数** = 各类 c 的类条件均值 $\mu_{j,c,q}$ 跨源港 q 的方差，再按类平均、按该维总体标准差归一：
  $$I_j = \frac{1}{|\mathcal C|}\sum_c \operatorname{Var}_q(\mu_{j,c,q}) / \sigma_j^2.$$
- $I_j$ 小 = 类条件分布跨港稳定 = **因果（不变）**；$I_j$ 大 = 随港漂移 = **伪（港专属）**。

## 判据（写死，不据以调参）
- 主判据：**只留 top-k 不变维**的 ridge 在目标港 macro BA 须 **> fusion(全 192 维, 0.471)**，才声称"因果因子挖掘有效"。
- 对照：伪维（bottom-k）应**显著低于**不变维与全维——证明方向对、不是随便删维都行。
- 若不变维 ≤ 全维，则因果挖掘在冻结 PCA 特征上不成立，如实报，回退现有方法。

## 协议
- LOPO；source 类分层子样本(seed 1000)；评估 query\ann；ridge(α=1, balanced)；BA/ACC 双列。
- 扫 k ∈ {48, 96, 144}（不变维）与对称的伪维，加全维(192)与 VV-only(128) 参照。

## 局限（诚实声明）
- 少数类可能只在 1–2 个源港出现，其跨港方差噪声大；PCA 维不是可解释"物理因子"，挖掘的是"特征方向的不变性"，不是语义因子。
