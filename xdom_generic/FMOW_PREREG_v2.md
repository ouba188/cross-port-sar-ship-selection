# FMoW 跨区域 · 预注册 v2（子样本口径）

日期：2026-10-05。前置：`FMOW_OFFICEHOME_PREREG_v1.md`（协议）、清单已建（426,994 张 / 62 类 / 0 失败）。

## 数据与分组
- 区域 = 多边形质心经纬度的**几何分区**（5 大区 + Other；规则确定性、与标签无关 ⇒ LOPO 有效）。
  Americas 143,519 / Asia 130,675 / Europe 113,468 / Africa 19,800 / Oceania 14,646 / Other 4,886。
- **子样本**：每（区域×类）细胞封顶 100 张，细胞下限 25（不足者剔除），`Other` 区不用。
  预期 ≈ 3.1 万张；最终数量以实际为准，写进结果。
- 划分：LOPO — 4 区训练、1 区测试（5 折）。

## 两视图
- 视图 A：ImageNet R50 avgpool 2048 → 源行 PCA-128；
- 视图 B：**采集元数据**（年份、季节相位 sin/cos、云量、GSD、太阳高度）——物理采集参数；
  **禁用经纬度/国家/UTM**（域身份泄漏）。
- base = ridge(A)、expert = ridge([A|B])、类别对键、预算 20%、三臂（rank_pair / rand / thr）。

## 判据（描述性，与 PACS 同口径）
- P1 支配率：expert BA ≥ base BA 的区数 / 有测试的区数；
- P2：支配区里 rank_pair ≥ rand 的比例；P3：支配区里 rank_pair > thr 的比例；
- macro BA 与按构成加权 ACC 两列都报；放宽口径：方向一致的正信号按初步结果保留，不因单一阈值关闭。

## 边界
- 子样本量 ≥25/细胞 是**保细胞多样性**，不为刷分；如某区细胞不足被剔，如实列出剩余区数；
- 本机 GPU 单卡：与 Office-Home 串行（不并发）。
